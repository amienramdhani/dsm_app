3 · Cara kerja

• Satu tempat untuk lihat dan atur siapa ASM dan RGM tiap sub region. Tabel di atas dibaca dari data user sekarang (atasan tiap orang).
• Saat disimpan, atasan di data user ikut berubah (sales → ASM, ASM → RGM), jadi Beranda, KPI, Edit target, dan akses ikut mengikuti. Tercatat di riwayat dengan alasan.
• Ada pratinjau dampak sebelum simpan: berapa sales/ASM yang pindah.
• Tanggal efektif: pilih Sekarang atau tanggal tertentu (ke depan). Berlaku mulai tanggal itu, tidak mundur; data bulan lalu tidak ditulis ulang.
• Admin dan Super Admin boleh ubah. Admin biasa hanya sub region di wilayah tugasnya; Super Admin semua.
• Asumsi: 1 sub region = 1 ASM = 1 RGM.
