Mockup · Filter "History Dealer per Brand" di desktop

Isi filter sama persis (Indikator, Brand, Bulan awal/akhir, Cakupan tanggal, Region, Sub region, Dealer/kode, Status promotor, Grade, Filter order lanjutan). Yang beda cuma susunannya. HP tidak berubah.

Catatan
  • A · Dikelompokkan: 3 kotak — PERIODE, DATA, WILAYAH & DEALER. Paling gampang dicari, sesuai aturan filter DSM (isi dikelompokkan berwarna).
  • B · Ringkas + Filter lain: 5 filter utama sebaris, sisanya di balik tombol FILTER LAIN (oren, sama dengan halaman lain). Paling hemat tempat.
  • C · Dua baris rata: semua filter dibagi 2 baris × 5 kolom sama lebar, tombol di bawah. Paling mirip sekarang tapi rapi.
  • Semua opsi: chip filter aktif + jumlah dealer + KOLOM / RESET / TAMPILKAN DATA di satu baris bawah.
  • D · Panel samping: filter selalu kelihatan, tapi tabel jadi lebih sempit (History tabel lebar → kurang cocok).
  • E · Kapsul sebaris: paling ringkas & modern (1–2 baris saja), nilai filter langsung kebaca.
  • F · Kalimat: unik & gampang dipahami orang baru, tapi makan tempat kalau filter banyak.
  • Rekomendasi gue: A atau E.
